## Building the site

This is a static site. `index.html` is self-contained — open it directly in a browser, or serve from any static host. GitHub Pages serves it from the `main` branch root.

The CSS uses a dark-luxury editorial design system with theme-toggle support; click the sun / moon icon in the top-right corner to switch between dark and light modes. Mermaid diagrams render client-side via CDN. No build step.
